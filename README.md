# Z-Coins 💹

**A modern crypto trading simulation platform built for speed, clarity, and real-time market experience.**

---

## 🚀 Overview

Z-Coins is a high-performance crypto trading frontend application built with **React (Vite)** and **Tailwind CSS**. It delivers a smooth, production-like trading experience where users can simulate cryptocurrency trading using a demo account powered by live-style API data.

Designed with a focus on performance, responsiveness, and modern UI/UX, Z-Coins replicates the feel of a real trading platform while remaining a frontend-focused learning and portfolio project.

## ⚙️ Core Features

- 📊 Real-time crypto market simulation interface
- 💰 Demo trading system for practice-based trading
- 📈 Interactive and dynamic charts using ApexCharts
- 🔔 Toast notifications for real-time feedback
- 🎨 Smooth animations and transitions with Framer Motion
- 🔐 Google OAuth authentication integration
- 🧭 Multi-page navigation with React Router DOM
- 📱 Fully responsive design across all devices
- ⚡ Optimized performance with Vite bundler

## 📦 Installation

```bash
# Clone the repository
git clone <repository-url>

# Move into the project directory
cd z-coins

# Install dependencies
npm install

# Start development server
npm run dev
```
