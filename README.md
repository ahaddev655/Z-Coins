# Z-Coins 💹

Z-Coins is a modern crypto trading frontend application built with React (Vite) and Tailwind CSS. It provides a smooth and interactive user experience where users can simulate trading cryptocurrencies using a demo account. The platform integrates live market-style data through APIs provided by the Z-Coins service.

---

## 🚀 Features

- 📊 Live crypto market-style trading interface  
- 💰 Demo trading account functionality  
- 📈 Interactive charts for price visualization  
- 🔔 Real-time notifications and alerts  
- 🎨 Smooth UI animations and transitions  
- 🔐 Authentication flow (Google OAuth supported)  
- 📱 Fully responsive design for all devices  

---

## 🛠️ Tech Stack (Frontend)

- React (Vite)
- Tailwind CSS
- ApexCharts
- Axios
- React Router DOM
- Framer Motion
- React Icons
- Lucide React
- React Toastify
- @react-oauth/google
